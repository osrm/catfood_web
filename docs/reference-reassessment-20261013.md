## 왜 현재 화면이 비어 보이는가 — 디자인 해석

1. **공간의 중심이 약하다.** 넓은 화면에 검색창, 안내, 구분선, 작은 제품이 펼쳐져 있지만 한 가지를 주인공으로 읽히는 장면이 부족하다. 단순히 흰 픽셀을 채우라는 뜻은 아니다.
2. **기능 이름이 서비스 경험을 대신한다.** 제품 찾기/조건 선택/정보 둘러보기는 할 수 있는 일의 목록이다. 실제 제품을 놓고 어떤 질문에 답을 얻는지 먼저 보여주는 장면이 약하다.
3. **메타데이터의 표현이 반복된다.** 작은 글씨·얇은 선·비슷한 제목 크기가 계속돼 사용자가 읽을 중요도를 대신 판단해야 한다. 데이터가 적은 화면은 작은 값과 큰 여백만 남는다.
4. **중립성을 화면 전체에 과도하게 적용했다.** 제품의 우열을 판정하지 않는 원칙은 맞지만 브랜드의 표현력, 제품 사진의 존재감, 친절한 말투까지 약화할 이유는 없다.
5. **기능 검증을 디자인 승인처럼 다뤘다.** 테스트·포커스·overflow·첫 화면 행 수는 중요한 기능/가독성 증거다. 매력, 신뢰, 관심, 제품 완성도를 증명하지 않는다. 이 구분을 이후 보고에서도 유지한다.

기존 Stitch 입력에는 색·폰트·구성을 자유롭게 고르라는 지시가 이미 있었다. 이번 문제를 단순히 'Stitch에 색을 강제했기 때문'이라고 결론내리지 않는다. 생성 후 실제 제품에 가져오면서 표현력이 줄어든 판단과, 반복적으로 채택한 작은 사진/기록 목록/중립 토큰을 함께 검토해야 한다. 이번 재검토에서 새 Stitch 화면을 생성했다고 주장하지 않는다.

## 다음 실제 디자인 작업의 기준

**중립적인 사실을, 소비자가 탐색하고 이해하고 싶게 보여준다.** 29CM를 주 시각 레퍼런스로 두고 Tuft & Paw는 제품 존재감, Apple은 비교 위계에 한정한다. 모든 사이트의 색/폰트/카드 모양을 평균내지 않는다. RTINGS와 Smalls는 역할·생활 맥락을 확인하는 보조다.

- HOME: 검색 입구와 실제 제품/비교로 얻는 것을 한 장면에서 연결한다. 유용한 서비스임을 구호로 선언하기보다 실제로 이용 가능한 탐색/비교의 짧은 예를 보여준다. 작은 예시 사진만 키우거나 큰 빈 hero를 추가하는 것으로 끝내지 않는다.
- 결과: 이름 검색의 빠른 훑기와 제품 발견의 관심 형성을 구분한다. 정확한 브랜드/전체 이름/규격/직접 비교를 유지하면서 사진과 정보의 강약을 다시 구성한다. 그리드나 목록 자체를 금지하지 않는다.
- 상세: 제품 사진·정체성과 현재 확인한 핵심 사실이 먼저다. 적은 자료를 빈 표나 경고로 채우지 않는다. 원문/자료 접근과 값에 영향을 주는 예외를 보존한다.
- 비교: 큰 실제 값/같은 축/정확한 단위와 qualifier로 차이가 눈에 잡히게 한다. 표현력 있는 중립 그래픽은 가능하나 임의의 유불리·안전/건강 점수는 만들지 않는다. 요약부터 보는 흐름과 세부 표를 함께 쓴다.
- 말투: 소비자의 궁금한 질문과 다음 행동을 말한다. 보완/범위/일치 여부의 내부 처리 용어를 기본 화면의 설명으로 다시 늘리지 않는다. 주의사항이 반드시 필요한 예외는 계속 보여준다.
- 색/폰트: 현재의 흰 배경·Pretendard·녹색을 반드시 유지하거나 반드시 버리라고 정하지 않는다. 대비와 제품의 강약, 서비스 정체성을 함께 판단한다. 모든 제품 데이터를 같은 회색/작은 글씨로 낮추거나 색으로 영양 우열을 암시하지 않는다.

첫 실제 작업은 HOME과 대표 결과 화면의 연결된 구성에 한정한다. 바로 전체 사이트를 갈아엎거나 새 기능을 약속하지 않는다. 새 구성의 원본을 먼저 보고 실제 React/공개 데이터/상태 왕복으로 이어 검증한다. 외부 사진·로고를 제품 자산으로 복사하지 않는다. 근거 없는 가격/리뷰/추천/건강 효과/저장·공유·계정 기능을 추가하지 않는다. 사용자가 지시하기 전 사람 대상 검토는 하지 않는다.

## 검토와 완료 조건

기능 확인은 실제 데이터·전체 제품명·단위/원문·state/history·키보드·작은 화면 가독성으로 한다. 디자인 판단은 별도로 사진/글자/중요 값/행동의 강약과 레퍼런스 대비 구체적인 차이를 기록한다. 첫 숫자 위치나 노출 행 수만 좋아졌다고 디자인 합격을 선언하지 않는다. 사람이 좋아할 것이라고 확정하지 않는다. 막연한 색/여백 조정을 끝없이 새 과제로 만들지 않는다.
