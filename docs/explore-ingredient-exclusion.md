# 일반 탐색: 피하고 싶은 원료

일반 탐색(EXPLORE)의 추가 조건에서 고른 원료가 공개 검토 자료에 확인된 제품을 제외한다. 제품에 원료가 없거나 알레르기에 안전하다고 판정하는 기능이 아니다.

- 지원 항목은 `src/search.ts`의 `INGREDIENT_AVOID_OPTIONS`에 있는 23개 동물 유래 원료다. 모든 원재료·원료 계열을 지원하는 사전이 아니다.
- 레시피 이름과 원료 근거를 구분한다. generic fish/poultry, 불명확한 향미 표현을 특정 종으로 추정하지 않는다.
- 기존 catalog의 `confirmed_present_ingredient_terms` 중 선택한 항목이 하나라도 있으면 제외한다. 기존 SWITCH처럼 direct/flavor를 포함하는 확인 집합을 사용한다.
- 남은 제품에서는 `reviewed_not_found_ingredient_terms`의 미발견과 그 외 근거 부족을 별도 표시한다. 목록에 없다는 사실을 원료 부재로 변환하지 않는다.
- 원료 제외 상태를 positive match 개수나 품질·안전 점수에 넣지 않는다. 기존 형태·연령 및 positive 정렬과 recipe refine OR는 유지한다.
- 현재 catalog 배열만 사용한다. 조건 선택마다 API 요청을 추가하거나 원재료 전문·영양 데이터를 전수 선조회하지 않는다.

## 상태와 비교

일반 탐색 URL은 `avoidIngredients=chicken,duck`처럼 검토된 term만 저장하며 중복·지원하지 않는 값은 제거한다. SWITCH URL과 session의 기존 원료 회피 설정은 별도다.

조건 편집 draft는 적용 전까지 마지막 적용 조건을 바꾸지 않는다. 같은 원료 집합을 재적용하면 비교 목록을 유지하며, 원료 선택 순서는 조건 변경으로 취급하지 않는다. 실제 조건을 바꾸어 적용하면 기존 비교 초기화 정책을 따른다.

EXPLORE↔LOOKUP, 상세 왕복, 뒤로/앞으로와 새로고침에서 마지막 적용 조건과 비교 맥락을 유지한다. Home에서 새 일반 탐색을 시작하면 이전 조건은 지운다.

LOOKUP에서 수동으로 추가한 제품에 피하려는 원료가 확인되어도 비교 목록에서 자동 삭제하지 않는다. 비교 화면에 “피하려는 원료 확인”, 미발견, 미확인을 각각 표시한다.

기존 값·단위·제품/SKU/Formula 의미와 최대 5제품 비교·기존 SWITCH 판단은 바꾸지 않는다.
