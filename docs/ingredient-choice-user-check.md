# 원료 정보 선택 과제

실제 보호자가 선택 이유와 정보의 한계를 이해하는지 관찰하기 위한 진행안이다. 아직 사람 대상 검증을 실행한 결과는 없다. 자동 브라우저의 예시 데이터 검증과 실제 사용성 검증을 구분한다.

## 진행

서로 다른 보호자 5명을 첫 관찰 대상으로 삼는다. 처음에는 사용법이나 원료 판정의 정답을 설명하지 않는다. 참가자가 막히면 먼저 막힌 지점을 기록하고, 설명 후 성공과 설명 없이 성공을 나누어 기록한다. 선택한 사료의 건강상 적합성을 평가하는 과제가 아니다.

1. 현재 먹이는 사료를 찾아 다른 후보 하나와 비교해 주세요. 후보를 선택한 이유를 말씀해 주세요.
2. 원료표에 `어유`가 있는 제품에서, 연어에 대해 어디까지 알 수 있는지 설명해 주세요.
3. 전체 원료표가 있는 제품과 일부 원료표만 있는 제품을 비교해 주세요. 두 제품에서 추가로 확인하고 싶은 것이 있나요?

과제 2·3에는 실제 공개 자료에서 해당 상태를 확인한 제품만 사용한다. 예시 fixture를 사용할 때는 실제 제품이 아닌 설명용 예시임을 알리고 실서비스 사용성 결과와 분리한다. 제품을 보여주기 전 국내/해외 자료의 적용 범위도 확인한다.

## 관찰 기록

| 항목 | 기록 |
| --- | --- |
| 후보 찾기·비교 | 설명 없이 성공 / 도움 후 성공 / 중단, 막힌 위치 |
| 선택 이유 | 참가자가 말한 실제 제품 차이 |
| 어유 이해 | 생선기름 포함은 확인되지만 연어 포함 여부는 미확인으로 남는다는 점을 이해했는지 |
| 자료 확보 범위 | 전체 원료 목록 확보와 세부 어종 기재를 구분했는지 |
| 자료 적용 범위 | 해외 자료가 국내 판매 제품에 그대로 적용된다고 오해했는지 |
| 남은 불확실성 | 참가자가 직접 말한 추가 확인 사항 |

이름·연락처·계정은 기록할 필요가 없다. 인용이 필요하면 동의를 받은 익명 발언만 적는다. 기존 서비스의 자동 수집 설정을 바꾸지 않는다.

## 다음 수정 판단

‘어유의 어종 미기재’를 ‘연어 없음’으로 이해하거나, 전체 원료표 확보를 모든 세부 정보의 공개로 이해하는 사례가 있으면 해당 문구·배치를 먼저 수정한다. 서로 다른 제품/자료 범위를 하나의 현행 배합으로 이해하는 경우도 같은 우선순위로 처리한다.

막힌 단계와 오해를 바탕으로 다음 변경 한 묶음을 정한다. 다섯 명의 관찰을 전체 소비자에 대한 검증 완료나 제품 적합성 증거로 일반화하지 않는다.
