# Brand search aliases

Aliases are search labels; they do not rename brands/products or merge catalog records. Reviewed Korean spellings come from Korean brand/importer catalogs and Korean retail product names. They are not necessarily official registered brand names. Case, spaces and the existing standalone and/& rule still use lookupCatalog's normalizer; punctuation variants are explicit labels instead of a global punctuation rewrite.

Purina/퓨리나 is a parent search across the existing 퓨리나, Purina Cat Chow and Purina Pro Plan records. Cat Chow and Pro Plan aliases stay in their own groups. Shared ownership does not make GO! SOLUTIONS/NOW FRESH or NutriSource/PureVita/Element Series one search brand.

## Held spelling

Naturo still searches by its catalog English name. A Korean spelling was not verified from the available Korean source page, so 나투로/나투루/나튜로 are not registered. Revisit only when a Korean brand/importer or exact Korean product source confirms the spelling. The source catalog currently has seven Naturo products.
