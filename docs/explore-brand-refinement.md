# 일반 탐색: 브랜드로 더 좁히기

조건 검색 결과의 `더 좁혀보기`에서 브랜드를 복수 선택한다. 선택한 브랜드 중 하나에 해당하는 제품만 남기는 OR refine이며, 형태·연령·원료 제외·레시피 조건과는 AND로 결합한다.

- 카탈로그의 정확한 brand 문자열을 identity로 사용한다. 한글·영문 검색 별칭은 선택 항목을 찾는 데만 쓰며, 상위 브랜드와 제품 라인을 합치지 않는다.
- 카탈로그 전체의 브랜드 중 빈도가 높은 8개를 먼저 보여준다. 전체 보기·이름 검색을 제공하며, 접어도 선택 브랜드는 표시한다. 선택 후 해당 조건 결과가 0개가 될 수 있다.
- 브랜드 이름 검색은 선택 목록만 좁힌다. 검색어 입력이나 전체 보기로 결과 조건·비교 목록을 바꾸지 않는다.
- URL은 반복 `brands` 파라미터를 사용해 쉼표·&·+ 등의 이름을 보존한다. 중복/빈 값/과도한 값은 정리하고, 카탈로그 로딩 성공 후 실제 없는 브랜드만 제거한다. 로딩·오류 중 선택을 지우지 않는다.
- 브랜드 추가·해제·지우기는 비교 목록을 자동 삭제하지 않는다. 0개 결과의 브랜드 선택 지우기는 브랜드만 해제하며 레시피/기본 조건을 보존한다.
- 같은 기본 조건 재적용은 브랜드·레시피 refine과 비교를 보존한다. 기본 조건을 실제 변경해 적용하면 기존 정책대로 refine과 비교를 초기화한다.
- EXPLORE↔LOOKUP, 상세 왕복, URL 새로고침 및 history에서 적용 맥락을 보존한다. LOOKUP 결과를 브랜드 refine으로 숨기지 않는다. 비교에 다른 브랜드를 수동 추가하면 브랜드 차이를 표시하며 자동 삭제하지 않는다.
- Home의 새 일반 탐색은 초기화한다. SWITCH URL/session에는 이 브랜드 refine을 섞지 않는다.
- 이미 받은 공개 catalog만 사용하며 API/DB/schema/브랜드 사실/검색 별칭 자체를 수정하지 않는다. 브랜드 선택은 제품 품질·추천 점수가 아니다.

활성 taxonomy에서 이미 허용한 브랜드 REFINE의 구현 계약이며 추가 영양 범위 필터나 원료 범위 확장을 포함하지 않는다.
